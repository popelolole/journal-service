# Journal Service

Spring Boot service for the core journal functionality in the
[Healthcare Microservices Platform](https://github.com/popelolole/healthcare-microservices-platform).

Handles patients, doctors, encounters, observations and conditions through a
REST API.

## Tech

Java · Spring Boot · Hibernate/JPA · MySQL · JWT · Docker · Kubernetes

## CI/CD

GitHub Actions runs the Maven tests and builds and publishes a Docker image.
